Small fix release.

## Downloads

- **Windows:** `Taktpause.exe`. No installation; double-click to start. The file is not code-signed yet, so SmartScreen may warn: "More info", then "Run anyway".
- **Ubuntu:** `taktpause_0.18.1-beta_amd64.snap`. Install with `sudo snap install --dangerous ./taktpause_0.18.1-beta_amd64.snap`.
- `SHA256SUMS.txt`: checksums of both files.

GitHub Actions built these files from this repository. Check the build record with `gh attestation verify <file> --repo Farid-python/taktpause`.
