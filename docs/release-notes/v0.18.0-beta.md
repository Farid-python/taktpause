First public release of Taktpause, now free software under GPL-3.0.

## Downloads

- **Windows:** `Taktpause.exe`. No installation; double-click to start. The file is not code-signed yet, so SmartScreen may warn: "More info", then "Run anyway".
- **Ubuntu:** `taktpause_0.18.0-beta_amd64.snap`. Install with `sudo snap install --dangerous ./taktpause_0.18.0-beta_amd64.snap`.
- `SHA256SUMS.txt`: checksums of both files.

GitHub Actions built these files from this repository. Check the build record with `gh attestation verify <file> --repo Farid-python/taktpause`.

## New in 0.18.0

- New, calmer design: one main button per screen, smaller quiet buttons for the rest.
- The window takes a soft colour by state: green for focus, blue for breaks, sand and terracotta when the planned time is over. Buttons follow the same colour.
- Helpful options are on by default: floating timer, lunch reminder, snack reminder and state colours. Switch off what you do not want in Settings. Mild humour stays off.
- Smooth round dial with the time left.
- Start screen: recent tasks as one-click chips, and the work rhythms (25/5, 35/5, 50/10, 52/17, custom) as visible choices.
- "Started earlier" opens in place of the dial: quick choices, − and +, a timeline you can drag, and a button that says what will happen ("Start break from 14:23").
- Settings has four tabs: Timer, Reminders, Appearance, Data & about.
- Floating timer: choose size and see-through level; solid under the mouse; pulses softly when time is up.
- Insights redesigned: summary cards, "Focus per day" chart with the weekly average, timelines and task bars.
- About shows the licence and a link to the source code.

## Privacy

All data stays on your computer. No account, cloud sync or telemetry.
